## 1. 项目概述

**Watermark Fairy**（简称 **WF**，中文名 **水印精灵**）是一款 Windows 桌面端照片水印工具。

- **形态**：Windows 原生桌面应用（WPF）
- **联网**：需要联网（更新检查 + 云端模板同步）
- **商业模式**：免费增值（Freemium）—— 基础功能永久免费 + 增值功能订阅
- **目标体验**：极简 · 批量 · 云端模板

## 2. 目标用户

| 用户群 | 痛点 | 我们的解 |
|---|---|---|
| 个人摄影 / 爱好者 | 朋友圈发图需防盗用 | 拖拽即加水印 + 实时预览 |
| 电商运营 / 商家 | 大量商品图需批量打标 | 文件夹批量 + 占位符命名 |
| 设计 / 自媒体 | 多个平台风格统一 | 云端模板 + 多设备同步 |
| 小型工作室 | 团队风格一致 | 共享模板库 + 协作 |

## 3. 核心价值主张

> **把"加水印"这件事做到极简，把"多场景"这件事交给云端。**

- **极简**：3 步即可完成（拖入 → 调参 → 导出）
- **批量**：文件夹批量 + 命名规则 + 实时进度
- **云端模板**：一处配置，多设备同步，团队可共享

## 5. 商业模式

### 5.1 免费层（Free）

- 单文件 + 文件夹批量（无上限）
- 文字 + 图片 logo 水印
- 实时预览
- 本地模板（保存 / 加载）
- 导出 / 导入模板
- 启动时不强制登录

### 5.2 增值层（Pro / Pro Team）

**Pro 个人版**（订阅 ¥29/月 或 ¥199/年）：
- 云端模板同步（10 GB 配额）
- 批量队列（≥10 任务）
- 定时任务 / Watch 文件夹
- EXIF 工具
- TIFF / HEIC 输入
- 优先客服

**Pro Team 团队版**（¥99/月/5 人）：
- Pro 全部功能
- 团队共享模板库
- 团队成员管理
- 水印审计日志
- 集中计费

### 5.3 定价策略

- 30 天免费试用 Pro（首次启动可激活）
- 年付 8 折优惠
- 教育 / 非商用专属折扣（v1.1）

> ⚠️ **待 owner 拍**：定价区间（¥29/月 ¥199/年 ¥99/月/5 人）是否合理？是否需要永久买断版？

## 6. 验收标准（v1.0.0）

- [ ] 安装包 < 50 MB（Windows 10/11 x64）
- [ ] 启动到主界面 < 2 秒
- [ ] 单图加文字水印 < 1 秒
- [ ] 100 张图片批量 < 60 秒（i5 + 1080p JPG）
- [ ] 模板云端同步延迟 < 3 秒
- [ ] 崩溃率 < 0.1%
- [ ] 离线模式（无网络）本地功能完全可用
- [ ] 更新检查 / 自动下载安装

## 8. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| WPF 在 Linux 上无法本地 build | 🔴 高 | CI/CD 走 GitHub Actions Windows runner |
| 云端模板用户接受度低 | 🟡 中 | v1.0 弱化云端，主推本地 + 导入导出 |
| 图片格式兼容（HEIC 等） | 🟡 中 | Pro 层做，先主流格式全覆盖 |
| 国内备案 / 隐私合规 | 🟡 中 | 提前咨询法务，ICP + 算法备案并行 |
| 商业化转化率低 | 🟢 低 | 免费版功能已够用，转化不强求 |
